## 実施方法についての注記

本セッションでは検査サブエージェント（14 体）の並列起動を行わず、メインコンテキストで差分を直接レビューした。理由は 2 つ。

1. セッションの運用方針により、ユーザーの明示的な指示なくサブエージェントを起動しない
2. 差分に検査対象言語のソースファイルが 1 件も含まれず、各検査エージェントが読むべきコードが存在しない

対象コードを含む変更に対しては、通常どおり `/enso:ipa-security-check` を単独起動して並列検査を実施すること。
