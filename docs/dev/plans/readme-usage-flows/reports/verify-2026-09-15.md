## Issues Found

### Issue 1: 手動の dev-cleanup を「dev-loop が中断した（`status: failed`）後」に案内している（README.md:175）

- 現状: `` - `dev-loop` が中断した（`status: failed`）後や、PR を作らない構成で、自動で引き継がれなかったとき ``
- 問題: dev-cleanup は `status: shipped` の計画だけを候補にし、0件なら何もせず終了する（skills/dev-cleanup/SKILL.md:58,65）。`status: failed` の計画に `/enso:dev-cleanup` を打っても「後始末が必要な計画が見つかりませんでした」で終わる。中断後に要るのは dev-cleanup ではなく、残った問題を直して dev-loop をやり直すこと（skills/dev-loop/SKILL.md:83-88）
- あるべき記述（例）: `` - PR を作らない構成（`pr_number: null`）で、自動で引き継がれなかったとき ``。中断については「`dev-loop` が中断した（`status: failed`）場合は PR が Draft のまま残るので、報告された問題を解消してから進める（dev-cleanup の対象にはならない）」のように分けて書く
- 補足: plan.md:44 とタスクの Test Strategy 自体が「dev-loop が中断した後に手動で呼ぶ」を求めており、誤りの元は計画にある。skills/dev-loop/SKILL.md:161-172 は failed のとき「dev-cleanup を起動しない」と書いているだけで、手動実行で拾えるとは書いていない（拾えるのは「いいえ」を選んだ shipped の場合だけ: 同:172）

### Issue 2: dev-webtest の「テスト計画が無ければ内部で作る」が、`<plan-name>` を指定した例と合わない（README.md:194, 201）

- 現状: 194行目「テスト計画が無ければ `dev-plan` の計画から内部で作る」、201行目の例は `/enso:dev-webtest auth`
- 問題: `dev-webtest-plan` を内部実行するのは、**引数なし**で起動し、`docs/dev/webtests/plans/` にテスト計画が1件も無いときだけ（skills/dev-webtest/SKILL.md:134-137）。plan-name を指定して `docs/dev/webtests/plans/<plan-name>.md` が無い場合は、既存のテスト計画一覧から選ばせるだけで、生成しない（同:131-133）。README の例どおり `auth` を指定すると、計画が自動で作られることを期待させる
- あるべき記述（例）: 194行目を「引数なしで実行し、テスト計画が1件も無ければ `dev-plan` の計画を選んで内部で作る」にする。201行目の前に `/enso:dev-webtest   # 初回（テスト計画が無ければ dev-plan の計画から作る）` を置く、などで引数なしの場合だと分かるようにする
